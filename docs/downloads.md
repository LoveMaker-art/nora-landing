# 下载地址检查与重试

范围：只改网页下载。安装包内容、版本编号、安装与更新流程不变。

- 三个平台仍使用 `/api/download/:platform`。GET/HEAD 默认返回文件302；`?format=json`供网页解析，`&retry=1`要求复查。
- 15分钟内验证过的缓存可立即使用。过期后先HEAD验证；404/410存为missing，15分钟内不会再次使用该URL，包括预置文件。
- 重新扫描最多3页发布、每页最多6个对应平台候选，跳过草稿/预发布及失效文件。总外部请求时间限制18秒；用尽预算则明确失败或使用受限缓存，不承诺扫描无限历史。
- GitHub临时故障只允许使用24小时内验证成功且没有被标记删除的缓存。冷启动种子没有成功验证时间，必须检查后才使用。
- D1按平台保存30秒检查间隔，跨Worker实例生效。重试在间隔内返回429/Retry-After；不可用返回503，绝不跳到发布页。
- 网页保留原页，用隐藏下载frame发起文件请求。正常结果只提示“已发起下载”，恢复原卡片，不新增重试按钮。失败时只在卡片下方提示，卡片文字、颜色与下载图标不变。再次点击原卡片触发强制复查；冷却剩余时间显示在提示行，仅禁用对应平台。其他平台仍可选择。不能观测跨域文件接收完成。无JS/新标签打开保留原始校验接口链接。
- FAQ不再声称GitHub发布记录是备用文件源。

## GitHub优先与SourceForge备用（2026-10-08，源码已验证，尚未部署）

默认仍先查GitHub，正常查询和文件响应不额外请求备用站。GitHub文件请求失败时检查同一版本的SourceForge地址；版本查询失败时读取 `https://downloads.sourceforge.net/project/nora-tavern/channels/stable.json`。该目录保留正式版本、发布时间、资产uploaded状态、大小及SHA-256字段，不能用SourceForge默认下载或网页文件时间推测最新版。

18秒总预算保留，GitHub最多占前10秒，后续留给备用站。只接受本项目固定HTTPS入口和官方 `*.dl.sourceforge.net` 跳转，每跳校验相同项目及文件路径；前端只接受规范入口，保留三个平台原按钮、原下载统计和请求成功口径。JSON读取上限1MiB，HTTP200的HTML错误页不能作为文件。已验证的备用地址复用原D1缓存，缓存失效后优先重新检查GitHub。

针对性后端与前端22项测试及静态构建通过；未执行真实浏览器下载或官网部署。2026-10-08经用户确认后，备用站`channels/stable.json`与`v2.4.2/release.json`已上传；匿名HTTPS读取内容与本地审查清单逐字节一致。启动器共享网络源码在受控GitHub403下，从真实SourceForge取得两份清单并完整下载41461字节组件，SHA-256匹配。官网换源代码仍未部署，后续自动发布凭据尚未配置；目录上线不等于正式客户端或官网用户已获得换源行为。

## 失败回退
旧Worker可运行在新增表存在的数据库上；无需删表。回退会恢复旧版失效地址处理缺口，应明确记录。不得把部署回退说成下载流程已稳定。
