# 官网安装包下载

范围：官网与 GitHub Pages 原有三个下载按钮、现有 Cloudflare Worker 下载路由。安装包内容、统计接口、数据库结构、页面布局和云端部署流程不变。

## 版本定位

1. 网页调用 `https://noratavern.com/api/download/:platform?format=json`。优先读取 `https://jihulab.com/LoveMaker-art/nora-tavern/-/raw/main/channels/stable.json`，与启动器使用同一正式入口。仅接受正式标签、固定 GitHub 资源身份、平台匹配的文件名、非零长度和 SHA256 摘要；另行验证极狐实际文件可访问。
2. 返回的 `url` 保留 GitHub 的规范文件身份，供现有网页提取标签和文件名；不代表实际传输会访问 GitHub。极狐正常时，版本定位无需 GitHub API。
3. 极狐目录或文件检查失败后，查询 GitHub `/releases/latest`。若没有可用安装包，再按每页 5 条、最多 100 条扫描历史，避免一次拉取巨大历史列表。保留 1 MiB JSON 上限和总检查时限。GitHub 失败时可使用 SourceForge 正式目录。
4. 已验证结果缓存 15 分钟。更换缓存命名空间并更新灾备种子为酒馆 2.5.2 / 启动器 2.2.2，使旧缓存不会挡住本次替换。D1 中早于灾备种子的记录不会作为新鲜结果使用。
5. 只有元数据发现并验证了文件才能刷新“版本已检查”时间。仅检查旧文件仍可下载，不会将其重新标为最新。元数据故障下可保留近期已验证地址或验证灾备文件；这不证明最新版本已成功查询。
6. 数据库不可用时仍允许独立定位；30 秒复查间隔、平台独立失败和边缘请求合并保持不变。

## 文件传输

1. 网页将固定的 `<标签>/<安装包文件名>` 交给同一 Worker，仍使用原下载卡片、反馈和隐藏下载框。无 JavaScript 时，原链接也通过同一路由定位和下载。
2. Worker 按 **极狐 → SourceForge → GitHub** 尝试同一文件。每个来源在响应和首段读取阶段最多等待 8 秒，成功开始后解除准备计时。不会在换源时选择其他版本。
3. 三个来源均检查状态、二进制类型、空文件、明显错误页、长度和 Range；Windows 开头检查 MZ。固定来源和平台文件名校验防止任意网址代理；SourceForge 跳转只允许原项目同路径官方镜像。
4. 流式交付，不把完整安装包存入 Worker 内存。保留附件文件名、长度和 206；单段 Range 可用于续传，非法或多段 Range 返回 416。HEAD 只读一个字节验证后返回完整长度。
5. 全部来源失败返回 503 和中文说明，网页验证消息来源、窗口、平台和文件身份后在原按钮显示失败与冷却。已经开始传输后若中断，不会拼接另一份响应；浏览器或下载工具可重新发起 Range。
