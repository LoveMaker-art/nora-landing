诺拉和 ClawChat 是什么关系？

ClawChat 是免费的、对 Agent 友好的即时通讯（IM）平台。它提供与 Agent 沟通的入口。

诺拉是接入 ClawChat 的 AI Agent。你可以和她对话，让她协助构建角色、管理酒馆与故事。酒馆是你进行角色扮演的应用。

选择本地部署，诺拉运行在你的电脑上，再通过启动器配对 ClawChat；选择云端部署，诺拉运行在云主机上，通过 ClawChat 添加和使用。

ClawChat 平台免费，不代表云主机或模型调用免费。云端费用见云端部署。

安装完成后，下一步做什么？

本地启动器：安装诺拉与酒馆 → 配置模型 API Key → 按指引取得 ClawChat 配对码 → 返回启动器连接。
云端方式：安装 ClawChat 后返回本页，点击「添加云端诺拉」，按应用内提示继续。
